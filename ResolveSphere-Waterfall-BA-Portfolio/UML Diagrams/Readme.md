# Visual Process & UML Modeling Artifacts

This directory contains the behavioral and architectural modeling diagrams developed to translate business requirements into technical system workflows.

---

## 📌 Modeling Overview

To bridge the gap between business stakeholders and the engineering implementation team, system interactions and business processes were visually engineered using industry-standard modeling tools:

* **Use Case Diagrams:** Designed to establish system boundaries, define primary and secondary actors, and map functional scope using standard UML relationships (`<<include>>`, `<<extend>>`, and actor generalizations).
* **Activity Diagrams:** Developed to detail procedural flows, parallel workflows (utilizing Fork and Join synchronization bars), decision branching logic, and error/exception paths.

---

## 🛠️ Tools Utilized

* **Microsoft Visio:** Utilized for formal enterprise-grade UML 2.5 modeling, structured technical architecture stencils, and stage-gate engineering documentation.
* **Draw.io:** Employed for rapid collaborative drafting, iterative diagramming, and cross-platform vector export (PNG/SVG/PDF).
